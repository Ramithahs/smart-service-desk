Smart Service Desk Management System
Problem Statement
This application helps support teams manage employee service requests such as laptop issues, software issues, network problems, password resets, and access-related requests.
Features
Create Service Request
View All Requests
Search Request by ID
Resolve Request
JSON Data Persistence
Concepts Used
Object Oriented Programming (OOP)
Exception Handling
File Handling
SOLID Principles
Domain Driven Design (DDD)
Git Branching and Merging
Project Structure

Running the Application
